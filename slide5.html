equals() Contract Rules

According to Java specification

Reflexive

An object must be equal to itself

a.equals(a) == true

Symmetric

If a equals b, then b must equal a

a.equals(b) ⇒ b.equals(a)

Transitive

If a equals b and b equals c, then a equals c

a=b and b=c ⇒ a=c

Consistent

Same result if object data unchanged

Multiple calls return same result

Non-null

Any object compared with null must return false

a.equals(null) == false
