What is equals()?

Logical Equality

Used to check logical equality between two objects based on their content

Different from ==

== compares references (memory addresses), while equals() compares content

Override Capability

Can be overridden to compare object data based on business logic

Practical Example

Two users with the same ID should be considered equal

Code Example

User user1 = new User("101", "Alice");
User user2 = new User("101", "Alice");

// Reference comparison
user1 == user2  // false

// Logical comparison
user1.equals(user2)  // true

Key Insight

Both users have ID "101", so they are logically equal even though they are different objects in memory
