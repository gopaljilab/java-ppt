hashCode() Contract Rules

Rule 1

Equal Objects → Same Hash

If two objects are equal according to equals(), they must have the same hashCode()

a.equals(b) ⇒ a.hashCode() == b.hashCode()

Rule 2

Same Hash ≠ Equality

Same hashCode() does NOT guarantee objects are equal

a.hashCode() == b.hashCode() ⇏ a.equals(b)

Rule 3

Collisions Allowed

Hash collisions are permitted. Different objects can have the same hash value

Multiple objects → Same bucket

Rule 4

Consistency Required

hashCode() must remain consistent during object lifetime if data unchanged

Same object → Same hash (always)
